# 🤖 Pythonic Autonomous Robot Controller

An educational, high-performance robot controller built with advanced "Pythonic" design patterns.

## 🌟 Key Features / Öne Çıkan Özellikler
- 🚀 **O(1) Event Mapping:** Zero `if-else` blocks for ultra-clean movement handling.
- ⚡ **Memory-Efficient Telemetry:** Built with Python Generators for low-RAM streaming.
- 🎯 **Type Safe:** Fully typed architecture using Python Type Hinting.

🤖 Ahududu Pi Robot Kontrol Mimarisi & Gelişmiş Python Uygulamaları🤖 Raspberry Pi Robot Control Architecture & Advanced Python ImplementationBu proje, Raspberry Pi üzerinde çalışan bir mobil robotun motor ve sensör yönetimini gerçekleştiren, modern Python (3.10+) tasarım örüntüleri ve donanım kilitlenme korumalarıyla optimize edilmiş açık kaynaklı bir kontrol sistemidir.This project is an open-source mobile robot control system running on Raspberry Pi, optimized with modern Python (3.10+) design patterns and hardware deadlock preventions.🚀 Öne Çıkan Gelişmiş Yazılım Mimarileri / Advanced Software Architectures1. Thread Kilitlenme (Deadlock) Koruması & SingletonTürkçe: gpiozero kütüphanesinin mesafe sensörü okumalarında yaşayabildiği thread kilitlenme (deadlock) hatalarını aşmak için arka planda threading.Lock() mekanizması kurulmuştur. Sensör yönetimi, sistem genelinde tek bir örnek üzerinden güvenle yürütülmesi için Singleton tasarım örüntüsüyle (_global_sensor) zırhlandırılmıştır.English: To prevent potential threading deadlock failures during ultrasonic distance readings within the gpiozero library, a strict threading.Lock() mechanism is implemented. The sensor management is wrapped inside a Singleton pattern (_global_sensor) to ensure thread-safe global access.2. Veri Yapıları ile Temiz Pin Yönetimi (Dataclasses)Türkçe: Donanımsal pin tanımlamaları kod içerisine rastgele dağıtılmak yerine, PEP 8 standartlarına uygun bir SensorAyarlari / Pinler dataclass dummy yapısı altında merkezi hale getirilmiştir. Bu sayede kablo ve pin değişiklikleri tek bir merkezden yönetilir.English: Hardware pin configurations are completely centralized using Python dataclasses (e.g., SensorAyarlari), strictly complying with PEP 8 standards. This layout eliminates magic numbers in code and provides single-point control for wiring layout updates.3. İf'siz Mimari: Sözlük Tabanlı Aksiyon Mantığı & LambdaTürkçe: Karmaşık ve işlemciyi yoran if-elif-else bloklarını ortadan kaldırmak için yön komutları bir Python sözlüğünde (dictionary) fonksiyon nesneleriyle eşleştirilmiştir. Fonksiyonların sözlük tanımlandığı an erkenden tetiklenmesini engellemek için lambda: ifadesiyle komutlar ileride çalıştırılmak üzere paketlenmiştir.English: To bypass CPU-heavy if-elif-else chains, directional robot commands are mapped to function objects inside a clean Python dictionary. Commands are wrapped using lambda: expressions as delayed execution packages, preventing functions from triggering instantly during dictionary instantiation.4. Pygame Döngüsünde Modern Kalıp Eşleştirme (Match-Case)Türkçe: Pygame olay döngüsü (event loop), Python 3.10 ile gelen gelişmiş match-case mimarisiyle yeniden tasarlanmıştır. Klasik dillerdeki kısıtlı switch yapılarına kıyasla Python'ın sunduğu Guard (Koşullu Muhafız) özelliği kullanılarak, tek satırda hem olay tipleri filtrelenmiş hem de klavye/fare aksiyonları dinamik olarak yönetilmiştir.English: The Pygame event loop is refactored using Python 3.10+ robust match-case pattern matching. Leveraging Python's Guards (conditional expressions), the loop dynamically captures event types, specific key triggers, and mouse movements inside single-line patterns, outperforming traditional switch-case blocks.🛠️ Kod Standartları (Coding Standards - PEP 8)Projedeki tüm isimlendirmeler ve kod düzeni kurumsal Python standartlarına (PEP 8) tam uyumludur:Classes (PascalCase): MesafeKontrol, SensorAyarlariFunctions & Variables (snake_case): robotu_hareket_ettir(), sol_motor_hiziConstants (UPPER_CASE): SG_GR = 24, MAX_HIZ = 1.0📂 Depo Yapısı / Repository Structure/ (Ana Dizin / Root): Modern tasarım örüntülerine sahip, temizlenmiş ve optimize edilmiş güncel kodlar./old (Eski Sürümler): Projenin gelişim sürecinde kullanılan eski, kararlı referans kodların yedekleri.Geliştirici / Developer: Nejat Uğurlu
