🤖 Pythonic Autonomous Robot ControllerAn educational, high-performance robot controller built with advanced "Pythonic" design patterns on Raspberry Pi.Bu proje, bir mobil robotun motor ve sensör yönetimini gerçekleştiren, modern Python (3.10+) tasarım örüntüleri ve donanım kilitlenme korumalarıyla optimize edilmiş açık kaynaklı bir kontrol sistemidir.🚀 Öne Çıkan Gelişmiş Yazılım Mimarileri / Advanced Software Architectures1. Thread Kilitlenme (Deadlock) Koruması & SingletonTürkçe: gpiozero kütüphanesinin mesafe sensörü okumalarında yaşayabildiği thread kilitlenme (deadlock) hatalarını aşmak için arka planda threading.Lock() mekanizması kurulmuştur. Sensör yönetimi, sistem genelinde tek bir örnek üzerinden güvenle yürütülmesi için Singleton tasarım örüntüsüyle (_global_sensor) zırhlandırılmıştır.English: To prevent potential threading deadlock failures during ultrasonic distance readings within the gpiozero library, a strict threading.Lock() mechanism is implemented. The sensor management is wrapped inside a Singleton pattern (_global_sensor) to ensure thread-safe global access.2. Veri Yapıları ile Temiz Pin Yönetimi (Dataclasses)Türkçe: Donanımsal pin tanımlamaları kod içerisine rastgele dağıtılmak yerine, PEP 8 standartlarına uygun bir SensorAyarlari veya Pin dataclass yapısı altında merkezi hale getirilmiştir. Bu sayede kablo ve pin değişiklikleri tek bir merkezden yönetilir.English: Hardware pin configurations are completely centralized using Python dataclasses (e.g., SensorAyarlari), strictly complying with PEP 8 standards. This layout eliminates magic numbers in code and provides single-point control for wiring layout updates.3. İf'siz Mimari: Sözlük Tabanlı Aksiyon Mantığı & LambdaTürkçe: Karmaşık ve işlemciyi yoran if-elif-else bloklarını ortadan kaldırmak için yön komutları bir Python sözlüğünde (dictionary) fonksiyon nesneleriyle eşleştirilmiştir. Fonksiyonların sözlük tanımlandığı an erkenden tetiklenmesini engellemek için lambda: ifadesiyle komutlar ileride çalıştırılmak üzere paketlenmiştir.English: To bypass CPU-heavy if-elif-else chains, directional robot commands are mapped to function objects inside a clean Python dictionary. Commands are wrapped using lambda: expressions as delayed execution packages, preventing functions from triggering instantly during dictionary instantiation.4. Geriye Dönük Uyumluluk ve Modern Kalıp Eşleştirme (Match-Case)Türkçe: Projenin ana kodlarında Raspberry Pi / Python 3.9 geriye dönük uyumluluğunu korumak adına Pygame döngüsü if-elif mimarisiyle çalıştırılmaktadır. Ancak geleceğe yönelik bir rehber olması açısından, Python 3.10+ sürümlerinde kullanılabilecek modern ve performanslı match-case (Pattern Matching) tasarım örneği ana kod dosyasının içinde yorum satırı (comment) olarak korunmuştur.English: To maintain backward compatibility (Python 3.9 and older) on edge devices like Raspberry Pi, the main Pygame event loop runs on if-elif logic. However, to serve as a modern architectural reference, the alternative Python 3.10+ match-case (Pattern Matching) implementation is preserved as a commented-out code block directly inside the core files.🛠️ Kod Standartları (Coding Standards - PEP 8)Projedeki tüm isimlendirmeler ve kod düzeni kurumsal Python standartlarına (PEP 8) tam uyumludur:Classes (PascalCase): MesafeKontrol, SensorAyarlariFunctions & Variables (snake_case): robotu_hareket_ettir(), sol_motor_hiziConstants (UPPER_CASE): SG_GR = 24, MAX_HIZ = 1.0📂 Depo Yapısı / Repository Structure/ (Ana Dizin / Root): Modern tasarım örüntülerine sahip, temizlenmiş ve optimize edilmiş güncel kodlar./old (Eski Sürümler): Projenin gelişim sürecinde kullanılan eski, kararlı referans kodların yedekleri.Geliştirici / Developer: Nejat Uğurlu
